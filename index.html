Developed an AI-based Android application that passively detects smartphone addiction risk in adolescents using live device usage data. Engineered a composite ML feature index aggregating 5 behavioural signals and trained a Random Forest classifier achieving 96.16% accuracy and 0.96 recall with zero false negatives. Built a full-stack system with Kotlin/Jetpack Compose Android client and Python Flask ML backend.
